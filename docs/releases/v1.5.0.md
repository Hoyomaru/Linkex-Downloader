# Linkex Downloader v1.5.0

v1.5.0 は、v1.4.0 の通常操作・single-file direct save・高速pipelineを維持しつつ、安全性修正と **複数共有リンクの一括取り込み** を追加する feature release です。

## Added

- 複数の `https://l2e.click/d/...` 共有URLを一括登録し、保存先を1回選んで共有ごとの既存高速Queueを順次実行する親バッチを追加。
- 同一share tokenを重複除外。
- 親バッチ状態をGM storage、保存先DirectoryHandleをIndexedDBへ保持し、ページ再読み込み後も現在の共有から再開可能。
- 容量skipが発生した共有では安全に一時停止し、再試行または次共有への継続を選択可能。

## Safety / correctness

- COPY/task応答のcreated/destination IDまたはtask IDとroot candidateを直接結び付けられる場合だけownershipを確定。
- 同名・同サイズ・単一ID差分だけではownershipを確定せず、安全停止。
- destructive DELETEは `ownershipProof.verified === true` と一致する `destId` を必須化。
- Range resumeの206応答は `Content-Range` の開始位置とrange幅を検証し、確認不能・不一致・Length矛盾時はpartialへ追記せず0 byteから再取得。
- direct-save targetをpicker直後にはtruncateせず、Queue metadata / FileHandleを永続化した後、実際のローカル転送直前に初期化。
- 診断文字列内へ埋め込まれたJWT / signed URLもredact。

## Reproducibility / CI

- test harnessでCRLFをLFへ正規化。
- `.gitattributes` でtext checkoutをLFへ固定。
- Release Asset builderもLF normalizeしてOS間で同一bytesを生成。
- GitHub ActionsをUbuntu / Windows matrixへ拡張。
