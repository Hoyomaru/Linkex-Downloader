# Linkex Downloader v1.4.0

2026-09-27

通常操作を簡潔にし、1ファイルだけ選んだときは余計なQueue folderを作らず直接保存できるbackward-compatible feature releaseです。

## 主な変更

- 初期画面を **すべてダウンロード / ファイルを選ぶ** の2操作中心へ整理
- 1件だけ選ぶと **このファイルを直接保存** に切り替え
- Save File Pickerで保存場所とfilenameをその場で確定
- direct-fileでもFileHandleをQueue復旧storeへ保持し、reload後にRange resume
- progress表示へ合計download速度 / 概算ETA / current fileを追加
- error時は次に取るべき操作を見つけやすい表示へ改善

## Direct-file safety

- 新規direct Queueだけ、Queue metadata構築後に既存targetを0 byteへ初期化
- reload/resumeでは再初期化せずpartialを継続
- browserで承認したfilenameをQueue metadataでも保持
- COPY ownership / signed URL / DELETE / final verifyは既存pipelineを共有
- 2件以上は従来どおりQueue directory + folder structure維持
