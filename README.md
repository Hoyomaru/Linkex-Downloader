# Linkex Downloader

Linkex の共有リンクから、共有内のファイルを 1 件ずつ安全にローカルへ保存する Tampermonkey userscript です。

Linkex の無料ストレージ容量を一時作業領域として使い、各ファイルごとに次の流れで処理します。

```text
共有ファイル
  ↓
Linkex 自領域へ一時コピー
  ↓
コピー先 ID を一意に確定
  ↓
署名付き CDN URL からローカルへダウンロード
  ↓
ローカル保存を検証
  ↓
自分で作成した一時コピー ID だけ削除
  ↓
次のファイル
```

## Version

実機で以下を順番に検証済みです。

- 共有リンク解析

- コピー先 ID の所有権確定
- CDN ダウンロード
- Range による再開
- 403 時のダウンロード URL 再取得
- ローカル保存サイズ検証
- 確定済み一時コピー 1 件だけの削除
- 複数ファイル Queue
- ページ再読み込み後の Queue 再開
- 全ファイル連続処理
- 容量不足ファイルの安全なスキップ
- 診断ログ出力

## Installation

1. Chrome / Edge に Tampermonkey をインストールします。
2. Releases またはリポジトリ内の配布 ZIP から `linkex_downloader_v1.0.0.user.js` を取り出します。
3. Tampermonkey で新規スクリプトを作成し、内容を userscript で置き換えて保存します。
4. Linkex にログインした状態で `https://disk.linkex.io/` を開きます。
5. 右下に表示される **Linkex Downloader** パネルを使用します。

## Usage

1. `https://l2e.click/d/...` 形式の共有 URL を入力します。
2. **共有リンクを解析** を押します。
3. ファイル数・合計サイズを確認します。
4. **全ファイル開始** を押します。
5. ローカルの保存先フォルダを選択します。
6. あとは Queue が 1 ファイルずつ処理します。

保存先にはジョブ専用フォルダが作成され、その中に共有側のフォルダ構造を再現します。

## Safety design

このツールでは、Linkex 上の既存ファイルを誤削除しないことを最優先にしています。

- COPY 成功レスポンスだけでは完了扱いにしない
- コピー前後の ID 集合を比較し、コピー先 ID を一意に確定
- COPY の結果が不明な場合は盲目的に再送しない
- ローカル保存が完了・検証されるまで Linkex 側のコピーを削除しない
- DELETE は `select_all: false` かつ確定済み `file_ids: [destId]` の 1 件だけ
- DELETE の結果が不明な場合も盲目的に再送せず、実状態を照合
- ページ再読み込み後は保存済み状態と Linkex 上の実状態を照合して再開
- 危険な曖昧状態では自動処理を停止

## Notes

- Queue 実行中は、別タブ・別端末から Linkex へファイル追加・コピーをしないことを推奨します。コピー前後の ID 差分を所有権判定に利用しています。
- 単一ファイル自体が Linkex の利用可能容量を超える場合、そのファイルは処理できません。
- Linkex 側の API / Web 実装が変更された場合、将来動作しなくなる可能性があります。
- 本ツールは Linkex 公式ツールではありません。

## Diagnostics

UI の **診断ログを保存** から JSON ログを書き出せます。

診断ログでは、認証 Token・共有 Token・署名付き URL などの機密情報を伏せて出力します。
